The block suspicious file extensions option uses the default list you've configured for the organization. To use a custom list, select the pencil icon then choose if you want the SVM to *Allow all file extensions except blocked list* or *Block all file extensions except allowed list*. Then, select the list from the dropdown menu. All storage VMs (SVMs) on the workload will use that list; you can later apply different lists to different SVMs on the workload. You must have configured link:task-file-extensions.html[a custom list]; you can also change or modify the selected list any time.
