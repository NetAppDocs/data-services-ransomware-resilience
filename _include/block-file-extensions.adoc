The block suspicious file extensions option uses the default list you've configured for the organization. To link:task-file-extensions.html[use a custom list] you've created, select the pencil icon.
+
If you've configured lists of blocked file extensions in ONTAP, you can override those lists by selecting *Replace ONTAP lists with Ransomware Resilience lists*. Then choose if you want the SVM to *Allow all file extensions except blocked list* or *Block all file extensions except allowed list*. Then, select the list from the dropdown menu. All storage VMs (SVMs) on the workload will use that list; you can later apply different lists to different SVMs on the workload.
