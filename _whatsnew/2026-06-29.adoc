=== Automated responses to user activity alerts

Ransomware Resilience now supports automated responses to user activity events. You can automatically block users and create a snapshot when a user activity alert is generated. These actions enable a swifter response without manual intervention. 

For more information, see link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-automate-user-activity.html[Automate responses to user activity alerts^].
