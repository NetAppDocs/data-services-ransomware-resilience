=== New manual user activity agent creation workflow

Ransomware Resilience now provides a manual user activity agent creation workflow, enabling more control in how you activate your user activity agent on your VM. With this new workflow, you can install the user activity agent directly and configure proxy settings without providing VM SSH keys. 

For more information, see link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/suspicious-user-activity.html#create-a-user-activity-agent[Create a user activity agent^].

=== Google Cloud NetApp Volumes Flex service level generally available

Support for the Flex service level from Google Cloud NetApp Volumes in Ransomware Resilience is now generally available (GA).
