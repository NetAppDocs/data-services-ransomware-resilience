=== Enhanced isolated recovery environment configuration

Ransomware Resilience now provides an enhanced isolated recovery environment configuration workflow. The new workflow clarifies and simplifies the process to set-up an isolate recovery environment for the cloud or on-premises environments. 

For more information, see link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-clean-restore.html[Create an isolated recovery environment for a clean restore^].

=== Google Cloud NetApp Volumes Flex service level generally available

Support for the Flex service level from Google Cloud NetApp Volumes in Ransomware Resilience is now generally available (GA).
