= Manage blocked or allowed file extensions in NetApp Ransomware Resilience
:hardbreaks:
:icons: font
:imagesdir: ./media/

[.lead]
NetApp Ransomware Resilience supports configuring a protection strategy that blocks suspicious file extensions. By default, Ransomware Resilience provides a list of blocked file extensions based on the nature of the workload. You can customize the list of file extensions, adding or removing file extensions as needed if the nature of the workload changes. You can configure file extension  so that the workload will automatically block specific file extensions. Alternately, you can create an allow list, such that only listed file extensions are allowed on the workloads; any file extension not on the list is automatically blocked. 

The default list of blocked file extensions is named "NetApp." You can modify this list or copy it to use as the basis for a custom list. It contains more than 3,900 known malicious file extensions. 

== Create file extensions list

If you've set specific file extensions in ONTAP to be blocked, Ransomware Resilience automatically inherits that list. If you modify the list of blocked extensions in Ransomware Resilience, that overrides the setting in ONTAP. 

.Steps
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**. 
. Select **Add**. 
+
image:blocked-file-extensions.png[Screenshot of blocked file extensions.]
. Enter a *Name* for the list. 
. Select how the list should operate: to create a list of blocked file extensions, select *Block extensions*. To create a list of permitted file extensions, select *Allow extensions*.
. Choose how to create the list:
* Select the *Copy list* tab to build from an existing list. 
+
Review the list of file extensions. Select the "X" next to the file extension type to delete extensions. Select *+ Add to list* to add additional extensions; this selection takes you to the *Enter manually* tab. 
* Select the *Upload* tab to add a list of blocked file extensions from a CSV file. 
+
Select *Upload* then choose a CSV file that includes the list of file extensions you want to block or allow. 
* Select *Enter manually* to type in the list. Enter the list as a set of comma-separated values, for example "vvv, xyz, zzz".
. Review the file extension list then select *Add* to create the new list. 
+
image:blocked-file-extensions.png[Screenshot of blocked file extensions.]

== Apply a file extension list to a storage VM (SVM)

The workload must include a detection policy that blocks suspicious file extensions before you can perform this task. Learn how to link:rp-use-protect.html[configure a ransomware protection strategy]. You can only assign one list of file extensions to each SVM. 

[TIP]
You can also assign a list of blocked or allowed file extensions for an SVM or a protection group when you enable protection with a block suspicious file extensions policy. 

.Steps
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Select the *Storage VM* tab. 
. Review the list of SVMs with the block suspicious file extension protections enabled. You can see which SVM uses which list. To change the list, select *Change list*.
. In the dialog, select the new list from the dropdown menu then select *Save*.

== Manage file extension lists

You can modify the contents of the file extension list at any time. You can delete a list or change a list to be the default for when you enable suspicious file blocking. 

.Modify a file extension list
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Identify the file extension list you want to modify. 
. To add file extensions to the list, select the action menu then *Add file extensions*. 
.. Choose the tab for the method you want to use to modify the list. Choose *Copy list* to import an existing list; choose *Upload* to import file extensions from a CSV file; choose *Enter manually* to manually submit file extensions. 
.. Select *Add* to save the changes.
. To remove file extensions, from the File extensions menu, select the name of the list you want to modify. 
.. In the list of blocked file extensions, select the checkbox next to each file extension you want to remove. At the top of the list, select **Remove**.
+
Alternately, select the action menu at the end of the row for the individual file extension you want to remove then *Remove*.
. Select *Save* to modify the list.

.Set a file extension list as the default
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Choose the action menu for the list that you want to make the default then *Mark as default list*.
. The list is then tagged as the default. Workloads protected with the blocked file extension list that haven't been marked with a specific list will block or allow file extensions based on the new default. 

.Delete a file extension list

You cannot delete a list that is designated as the default. If the list is currently set as the default, you must first designate a new list as the default before deleting it. You cannot delete the NetApp list. 

. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Select the action menu for the list you want to delete then *Delete list*.
. Confirm deletion in the dialog.
