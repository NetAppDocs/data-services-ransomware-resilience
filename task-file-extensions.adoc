= Manage blocked file extensions in NetApp Ransomware Resilience
:hardbreaks:
:icons: font
:imagesdir: ./media/

[.lead]
NetApp Ransomware Resilience supports configuring a protection strategy that blocks suspicious file extensions. By default, Ransomware Resilience provides a list of blocked file extensions based on the nature of the workload. You can customize the list of file extensions, adding or removing file extensions as needed if the nature of the workload changes. You can configure file extension block so that the workload will automatically block specific file extensions. Alternately, you can create an allow list, such that only listed file extensions are allowed on the workloads, meaning all others are automatically blocked. 

The default list of blocked file extensions is named *NetApp*. You can modify this list or copy and modify it. It contains 3,900 known malicious file extensions. 


== Create blocked extensions list

If you've set specific file extensions in ONTAP to be blocked, Ransomware Resilience automatically inherits that list. If you modify the list of blocked extensions in Ransomware Resilience, that overrides the setting in ONTAP. 

.Add blocked extensions
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**. 
. Select **Add**. 
+
image:blocked-file-extensions.png[Screenshot of blocked file extensions.]
. Enter a *Name* for the list. 
. Choose the function of the list: to create a list of blocked file extensions, select *Blocked extensions*. To create a list of permitted file extensions, select *Allowed extensions*.
. Choose how to create the list:
* Select the *Copy list* tab to build from an existing list. 
+
Review the list of file extensions and delete accordingly by selecting the "X" next to the file extension type. 
Select *+ Add to list* to add additional extensions. 
* Select the *Upload* tab to upload a list of blocked file extensions.
+
Select **Upload** then choose a CSV file that includes the list of file extensions you want to block or allow. 
* Select *Enter manually* to type in the list. Enter the list as a set of comma-separated values, for example "vvv, xyz, zzz".
. Select *Add* to create the new list. 

.Remove blocked extensions
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. In the list of blocked file extensions, select the box next to the file extensions you want to remove. 
+
image:blocked-file-extensions.png[Screenshot of blocked file extensions.]
. At the top of the list, select **Remove**.
. Select **Save**. 

== Apply a blocked extension list to a storage VM

The workload must include a detection policy that blocks suspicious file extensions before you can perform this task. Learn how to link:rp-use-protect.html[configure a ransomware protection strategy].

.Steps
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Select the *Storage VM* tab. 
. Review the list of SVMs with the block suspicious file extension protections enabled. You can see which SVM uses which list. To change the list, select *Change list*.
. In the dialog, select the new list from the dropdown menu then select *Save*.

== Manage lists

.Set a list as the default
. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Choose the action menu for the list that you want to make the default then *Mark as default list*.
. The list is then tagged as the default. Workloads protected with the blocked file extension list that haven't been marked with a specific list are now blocking or allowing file extensions based on the new default. 

.Delete a list

You cannot delete a list that is designated as the default. If the list is the default, you must first desingate a new list as the default before deleting it. You cannot delete the NetApp list. 

. In Ransomware Resilience, select **Settings**. 
. Under the File extensions heading, select **Manage**.
. Select the action menu for the list you want to delete then *Delete list*.
. Confirm deletion in the dialog.
